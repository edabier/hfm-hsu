# HFMs pretrained weights
To use this library, the pretrained weights of the desired model must be downloaded and added to this folder. 

This repository currently supports DOFA, SpecAware, HyperFree, HyperSL, HyperSIGMA, UniverSat, Panopticon and SpecViT
The weight are available at :
